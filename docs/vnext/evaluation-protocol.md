# P18 离线评测协议

P18 的第一步只处理已经记录的评测运行，不启动模型、工具或目标请求。输入
JSON 必须包含 `budget_usd`、`calls` 和 `results`；每个 `calls` 项使用网关已
记录的非负 Decimal `cost` 与 `role`。`reason`、`explore`、`summary` 以及未知
但已登记的角色全部计入同一个预算。

`scripts/vnext/run_evaluation.py` 输出每次结果的计数、按角色费用、总使用量、
剩余预算和是否超支，并保留 `trial_count`。它不会选择“最佳一次”覆盖重复试验，
也不会将缺失或非法费用当成零。

真实模型效果、真实目标和任何付费调用仍需单独批准；离线摘要不能证明自主效果。
因此未获批准的真实试验必须保持 `not_run`，而合成机制结果只证明机制路径。
