# 产品交互原型 Spec

状态：approved / 原型范围已获用户确认（2026-09-10）。基准：产品方案 `70e2aae`，业务代码 `381ae3a`。

依据：[已确认交互方案](../../product-interaction-proposal.md)。本批是独立模拟原型，不实施任何后端/API/数据库变化。

- 展示四步创建：场景目标、对象授权、配置、确认；真实可点击与保留输入。
- 两条路径：首批 HTTP（匿名/无模型）与完整 Agent 体验（模拟资料、身份、模型配置）。主题沿用现有五套，默认 silver。
- 保存草稿与创建区分；创建进入待启动，用户显式启动后才进入模拟执行状态。
- 详情提供任务配置、计划/时间线、证据联动、人工问题卡、暂停/恢复/取消、结果及关联复测。
- 用户新增明确要求参考 oritera/Cairn 黑板：完整 Agent 演示增加“黑板”视图，区分有证据的观察/Fact、待探索 Intent、人工 Hint；选择条目联动依据并可提交模拟 Hint。采用紧凑关系卡或列表即可，本批不开发通用图编辑器或引入图库；首批 HTTP 保持观察与证据，不伪造 Agent 黑板。
- 范围阻断可修复并保存草稿；环境不可用保留已创建任务；提交响应丢失刷新后按原命令恢复，不能再次创建/启动。
- 所有证据为合成数据，固定保留示例域名，显眼但简短标识“交互预览”；不调用真实 API、网关、目标或集群。
- 模拟持久化仅可保存合成演示数据，页面不允许录入真实凭据。新建用户输入只存内存；刷新恢复以模拟演示数据验证流程，不把任意目标/目标描述写浏览器存储。
- 可用浏览器前进/后退。模拟操作不得影响正式 4180 工作台；不把未来场景注册到正式产品。

验收：一次正式原型构建、必要 antd lint、一次连贯浏览器走查（创建→待启动→启动→问题/证据→取消→结果，并查看刷新恢复演示）。其余完整矩阵不在本批。共享检查上限 600 秒，通过即停止。
