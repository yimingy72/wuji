- 集成差异与暂存清单：待填写

- 代表性交互证据：待填写

- 未覆盖风险：待填写；没有时写“无”
- 最终结论与依据：待填写

只有主代理核对 Spec 验收项、实际验证基准、对应证据和未覆盖风险后，才能把阶段结论改为 `accepted`。验收不要求由另一代理执行；首次快照不构成验证证据，原型检查不能替代平台集成验收。

纯文档阶段将测试状态保持 `not-tested`，注明业务测试不适用，另记录文档审查基准和 diff / 链接检查结果；文档阶段可以据其 Spec 完成验收，不表示业务能力通过。
