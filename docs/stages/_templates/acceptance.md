> 模板默认状态为 `not-tested`，不表示通过。没有实际被测提交 SHA 和独立测试证据时，不得填写 `passed` 或 `accepted`。

- 测试状态：`not-tested`
- 阶段结论：`pending`
- 阶段：待填写
- 对应 Spec：[`spec.md`](spec.md)
- 对应 Plan：[`plan.md`](plan.md)
- 被测试代码提交 SHA：待填写
- 测试日期：待填写
- 独立测试执行者与模型：待填写
- 测试环境：待填写
- 验收记录提交 SHA：记录提交完成后再填写；不得预先填写

## 主代理复核

- 集成差异与暂存清单：待填写
- 关键契约复核：待填写
- 代表性交互证据：待填写
- CodeGraph 新鲜度或回退说明：待填写
- 未覆盖风险：待填写；没有时写“无”
- 最终结论与依据：待填写

只有主代理确认 Spec 验收项、实际测试 SHA、独立证据和未覆盖风险后，才能把阶段结论改为 `accepted`。首次快照、开发者自测或原型检查均不能单独作为阶段验收。
