# 阶段 Spec

> 模板默认状态为 `draft`。只有用户批准范围和验收标准后，主代理才能改为 `approved`；删除所有“待填写”项之前不得批准。

- 状态：`draft`
- 阶段：待填写
- 日期：待填写
- 负责人：主代理
- 批准依据：待填写；未批准时保留“无”

## 目标与范围

说明本阶段要产生的可观察结果、允许修改的系统边界和授权验证范围。

## 非目标

列出本阶段明确不实现、不迁移或不验证的事项。

## 行为与约束

描述用户可观察行为、安全边界、保留策略和失败处理。接口、数据模型或兼容性要求必须写明；无变更时明确写“无”。

## 验收标准

| ID | 可观察通过条件 | 验证入口 |

| S01 | 待填写 | 待填写 |

验收项应能绑定实际证据，不能把“已实现”或“检查过”本身作为通过条件。不要求另一代理执行才能验收，自行验证不得称作独立测试。纯文档阶段使用 diff 与链接检查，明确不代表业务实现或运行验收。
