## 范围规则

包含项为主机+是否含子域+明确协议端口对。排除优先，排除域名默认含自身及全部下级域，表单明确勾选；IP无子域。排除默认所有本任务已包含协议端口，高级可选具体组合。按域标签匹配，不通过DNS推断；路径不参与。
确认和详情完整显示包含/排除/期限；入口不在范围、被排除或有效范围为空不能创建但能保存草稿。包含/排除/入口/期限变化清除原范围确认。

## 创建恢复

客户端submitting/unknown/failed/succeeded与模拟服务端Task/receipt Map分开。发送前存原标识并deep clone冻结原请求。每个用户/项目最多一个待确认命令；同键重试只读原结果/保持单Task。超时/丢失/不可校验响应/回执404保持unknown，不自动新建。原请求在内存可重试原提交，否则仅核对。模拟刷新只丢原请求、保留标记与服务端Map；查询回执后再读对应Task才成功。查看列表后用户显式确认放弃核对才可新操作，不删除原任务。身份/项目切换隔离迟到响应；退出/身份变更清对应标记。

## 模型表单

服务名称/协议/BaseURL/Key必填；新增服务版本仅复制非秘密内容，Key必须重输；成功后清空Key和冻结请求中的Key。unknown保留原操作标识，先核对，不自动新键。服务无检查/发布动作。
方案名称、服务版本、模型ID必填；容量和输出可缺省保存但发布必填；输出<=容量，超时默认30秒/范围1..60。pricing可整体null，此时可检查不可发布；填写价格时来源和输入/输出价必填，不能静默丢部分价格。缓存模式新建不预选，摘要始终显示“未选择”或明确模式；standard_input清独立缓存价格，separate两项必填。复制版本显示原计价；单价字符串USD/百万Token，输入输出不能同时0。版本检查互不继承。
平台state与网关阻断状态分开：retired显示已停止发布；revoked且未确认显示“平台已禁用，网关阻断待确认”；确认后显示“平台已禁用，网关已确认阻断”，均不宣称在途全部停止。创建草稿保留失效模型名称/版本，立即阻止创建，不自动换模型。Operator不显示管理入口。
