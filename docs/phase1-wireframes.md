## 1. 用途和访问

运行 `pnpm dev` 后访问 `http://127.0.0.1:4173`。这是可交互的工作台视觉原型，验证三栏布局、Ant Design 多套明暗主题、页面信息顺序、状态文字和导航；它不是可交付的业务控制台，也不具备登录、租户隔离、后端分页或真实执行能力。

2026-09-09 根据用户反馈重构：任务队列、执行过程和响应证据同屏；深石墨底色搭配冷青强调，使用紧凑组件和等宽技术字段。移除页面介绍段落，演示说明和场景控制收进设置抽屉。后续反馈保留该结构，增加雾银、冰蓝、青瓷和亮石墨，默认使用雾银；原石墨作为对照保留。页头选择配色，`?theme=silver|glacier|celadon|slate|graphite` 可打开独立比较版本。完整视觉规则见 [DESIGN.md](../DESIGN.md)。

## 2. 四个页面

| 页面 | 信息顺序 | 核心动作 | 对应 API |
| --- | --- | --- | --- |
| 任务工作台 | 左侧队列与范围；中间任务状态、组件状态、执行记录；右侧证据检查器 | 名称/状态筛选、创建任务、取消、检查正文与元数据 | listTasks、getTask、listTaskEvents、listArtifacts |
| 创建与范围预览 | 名称/固定示例目标/方法 → 允许路径/排除项 → 有效期/限额 | 预览 → 修改后重新预览 → 创建任务 | previewTask、createTask |
| 任务详情 | 任务和目标 → 状态/调用数 → 阻断说明 → 时间线/证据 → 操作 | 取消；设置抽屉中模拟停止回执 | getTask、controlTask、listTaskEvents、listArtifacts |
| 证据详情 | 来源任务 → 分类和时间 → 纯文本正文 → 元数据 | 返回来源任务；本轮不提供下载按钮 | getArtifact、previewArtifact |

原型只绑定一组固定资源 ID；刷新恢复示例数据。新建动作在内存中将示例任务置为 queued，不建立真实 Task；未执行时不出现环境就绪和已产生证据的声明。当前创建页固定目标与范围，正式页面应从已批准 Scope 及服务端预览中选择。

## 3. 关键交互

用户修改名称或方法后，旧范围预览立即失效；重新预览后才出现创建动作。空名称显示关联字段错误。正式实现还需服务端重新校验预览、输入摘要和到期时间。

点击取消只进入“取消中”，显示等待停止回执。原型的“模拟停止与清理回执”属于评审工具，用来展示执行端确认后的界面；正式产品不提供这个按钮，也不能让用户手工宣称执行停止。

证据正文用 React 文本节点输出，夹具故意包含 script 和外部图片标签，以检查浏览器不执行或加载它们。展示原始标签不意味着这些内容受信任。正式下载、保留期和凭据脱敏由 API 完成。

## 4. 状态评审

左下角“演示设置”中的“演示场景”切换示例异常，不修改真实资源。取消流程使用“正常流程”；“结果不明”和“清理待完成”用于查看状态表达。

| 场景 | 必须看见 | 避免误解 |
| --- | --- | --- |
| 正常流程 | 当前执行状态、范围版本、调用数和证据入口 | 事件回放不会重新执行 |
| 取消中 | 接受取消、等待停止回执 | 接受请求不表示已停止 |
| 结果不明 | 待核对调用、不能直接重试的原因 | unknown 不属于业务未复现 |
| 清理待完成 | 已停止执行、出口撤销、单独的清理状态 | 执行终态不表示资源都已删除 |
| 无权限 | 当前项目不可访问，正文不继续展示 | 这仅是原型视图，不是服务端鉴权证明 |
| 空结果 | 没有匹配任务或证据不可用的具体说明 | 不使用“查询失败”代替空结果 |
| 查询失败 | 暂时无法获取数据，任务状态待重新获取 | 网络错误不能推断目标已停止 |

## 5. 工程验证边界

原型采用单个 ConfigProvider、Data Router 和共享 QueryClient，四个路径按路由加载，列表和详情共用工作台布局，响应正文与范围字段复用同一组件；类型来自 OpenAPI 生成物。通过本地测试只能确认这组依赖能配合构建，以及示例流程具有预期行为。

浏览器检查还覆盖队列筛选与重置、范围/证据切页，并覆盖创建预览失效、取消两阶段展示、证据脚本不执行/不外联、异常状态区分、深链接刷新、键盘入口与 390 px 窗口。当前流程截图写入 `artifacts/workbench-current/`，配色截图与对比度记录写入 `artifacts/palettes/`，属于本地验证产物。尚未验证真实会话、SSE、多个项目切换、生产代理、万条记录性能和完整可访问性要求。
